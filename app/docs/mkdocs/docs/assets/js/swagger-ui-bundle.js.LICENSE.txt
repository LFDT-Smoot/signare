Third-party vendored asset: Swagger UI
======================================

This directory vendors a pinned copy of Swagger UI, used by the
mkdocs `render_swagger` plugin (see app/docs/mkdocs/mkdocs.yml) to render the
OpenAPI specification in the documentation site.

Refresh / verify
----------------

To verify the vendored files against upstream (replace VER with the pinned tag):

    VER=v5.15.2
    base=https://raw.githubusercontent.com/swagger-api/swagger-ui/$VER/dist
    curl -sSL $base/swagger-ui-bundle.js | sha256sum
    curl -sSL $base/swagger-ui.css       | sha256sum

To bump the version, fetch the new dist files, update the version and both
SHA-256 values above, and confirm the new release post-dates the historical
Swagger UI DOM-XSS fixes (the core Swagger UI DOM-XSS issues were fixed well
before the 5.x line; see Known issues below for transitive dependency advisories).

Known issues
------------

swagger-ui-dist 5.15.2's dependency tree includes a prismjs version < 1.30.0,
affected by CVE-2024-53382 (DOM clobbering, medium). Prism highlighting here is
provided via refractor, and the site renders only our own static OpenAPI spec at
build time with no user-supplied input, so exposure is low. Bump the pin when a
newer Swagger UI ships the fixed prismjs.
